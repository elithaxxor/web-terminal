# Changelog

### Added
- Initial clone of Interactive Shell website with responsive frontend.
- Interactive terminal tab with real-time backend integration using WebSocket.

- AI assistant integration using OpenAI API.
- Shodan API integration with search page.
- Multiple terminal tabs and file explorer UI (file explorer to be implemented).
